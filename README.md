## Setup Environment

To create the venv environment, use the `requirements.txt` file found in the root of the repository. This contains all the necessary libraries to execute the code.

Choose an environment name in the space `<environment_name>`. Also, depending on the user's computer configuration, run the code with either python3, python or pip:
```bash
cd SOC
python3 -m venv <environment_name>
source <environment_name>/bin/activate
```

To deactivate the environment, use the folowing command:
```bash
source deactivate
```
